# Giới thiệu Next.js

Next.js là một framework xây dựng trên React, được phát triển bởi Vercel. Nó cung cấp nhiều tính năng giúp phát triển ứng dụng web dễ dàng và hiệu quả hơn.

## Tại sao chọn Next.js?

- **Server-Side Rendering (SSR):** Trang web được render phía server, giúp SEO tốt hơn và tải trang nhanh hơn.
- **Static Site Generation (SSG):** Tạo trang tĩnh tại thời điểm build, cực nhanh.
- **API Routes:** Xây dựng API backend ngay trong dự án Next.js.
- **File-based Routing:** Router tự động dựa trên cấu trúc thư mục.
- **Built-in Optimization:** Tối ưu hình ảnh, font chữ tự động.

## Cài đặt

```bash
npx create-next-app@latest my-app
cd my-app
npm run dev
```

## Kết luận

Next.js là lựa chọn tuyệt vời cho dự án React tiếp theo của bạn. Với hệ sinh thái phong phú và cộng đồng lớn, bạn sẽ luôn tìm được sự hỗ trợ khi cần.
